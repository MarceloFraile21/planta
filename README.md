# Planta — perímetro y reparto

Herramienta experimental para explorar distribuciones arquitectónicas a partir de un perímetro, un programa de locales y un conjunto de restricciones espaciales.

Desarrollado por Marcelo Fraile Narváez en el marco de FabBox URJC, Escuela de Ingeniería de Fuenlabrada, Universidad Rey Juan Carlos.

## Qué permite hacer

- Dibujar y editar un perímetro arquitectónico.
- Diferenciar fachadas y medianeras.
- Definir lados con o sin acceso.
- Establecer orientación norte y posición de acceso.
- Crear un programa de locales con dimensiones mínimas, superficie máxima y elasticidad.
- Definir condiciones de entrada, apertura, orientación y relaciones entre locales.
- Generar alternativas de distribución mediante búsqueda estocástica.
- Validar condiciones duras de accesibilidad, fachada, dimensiones, superficie y contigüidad.
- Comparar alternativas según relaciones, circulación, fidelidad al programa, regularidad, entrada, fachada, orientación y agrupación.
- Exportar la planta seleccionada como SVG o PNG.
